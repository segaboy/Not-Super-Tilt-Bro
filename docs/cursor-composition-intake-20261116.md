# ClasSICK cursor response evidence available to the port

2026-11-16. Reference-only intake of original project engineering evidence.
The [ClasSICK canonical receipt](https://github.com/segaboy/ClasSICK-0.97/blob/a0c91c71bd5a411b5f2ee1974efaa75d86354d97/docs/development/cursor-byte-composition-20261116.md)
identifies the shared Mono cursor optimization, exact Mac/286 images,
independent pixel tests, native timings and release-review package. That
immutable revision is local; this entry does not claim a successful push.

Explicit byte-row composition reduced the observed Mac cursor-move cost.
All matched modeled response cases improved, while recorded accepted mouse
vectors still reproduced the exact final state without losses. Axis/phase
timing differences and owner response qualification remain open. This
distinguishes drawing cost from gain and input delivery before changing
sensitivity. Measurements are BootHush observations, not physical timings.

This method is a candidate for the port's own mouse-title cursor investigation.
It has not been integrated or benchmarked in the game ROM. The existing
recovery-jump demonstration is retained unchanged in the refreshed paired
review archive; no new gameplay behavior or complete game is claimed.
No upstream game implementation was transferred into ClasSICK, and no
proprietary source or asset entered this intake.
